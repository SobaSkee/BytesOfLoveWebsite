# Bytes Of Website

Welcome to the website for **Bytes of Love**!

This website allows players to learn about what Bytes of Love is and get a download of the current game for FREE!

## 🌐 Website link

To explore the live website, click here: [bytesoflove.net](https://bytesoflove.net)

## 🚀 Features
- 📖 **About the Game:** Discover the story by with your favorite programming languages and the see inspiration behind *Bytes of Love*.
- 🎮 **Free Game Download:** Easily download the latest build of the game.
- 📰 **News & Updates:** Stay informed about upcoming features and events.
- 💌 **Community Engagement:** Connect with other players and share your experiences on the UFOSC discord.

## 💻 How to run locally
If you'd like to run the website locally on your machine for development or testing, follow these steps:

1. **Fork the repository**

   Start by forking this repository to your own GitHub account.

2. **Clone your forked repository**

   Clone the forked repository to your local machine:
 	```bash
 	git clone https://github.com/<your-username>/BytesOfLoveWebsite.git
 	```

3. **Navigate to the directory**

   Move into the project directory:
 	```bash
 	cd BytesOfLoveWebsite
 	```

4. **Install dependencies**

   Ensure you have Node.js installed, then install the required npm packages:
 	```bash
 	npm install
 	```

5. **Create environment variables (Optional)**

   If the project requires environment variables, create a `.env` file based on the provided `.env.example`.

6. **Start the development server**

   Launch the website locally:
 	```bash
 	npm start
 	```

After running this command, the website should be accessible via http://localhost:3000 or another port specified in the console.

## 🛠️ Building for production
To build the website for production:

```bash
npm run build
```

This will create an optimized `build` folder ready for deployment.
